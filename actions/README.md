# `actions/` — production wasm action modules

This directory hosts the production wasm action modules that implement archiform-declared verbs. Each subdirectory is one verb (e.g. `actions/mint/` implements the `mint` verb of `schemas/memory-palace-0.1.0.json`'s `x-actions` map). The Zig source is compiled to wasm32-freestanding by a `zig build <verb>-wasm` target; the produced `<verb>.wasm` is content-addressed by `blake3(wasm_bytes)`, with that fp recorded in the archiform schema's `x-actions.<verb>.implementation.wasm` field. Per D-031 the schema is the unit of trust: signing the schema transitively authenticates the wasm fp it pins. Per D-033 the only host imports are the five locked `dreamball.*` functions; any deviation is an architecture-decision event, not a story-execution decision.
