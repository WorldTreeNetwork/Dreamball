```
1. DISCOVER ──→ 2. MAP ──→ 3. PROFILE ──→ 4. BRIDGE ──→ 5. ALLIANCE
```

1. **Discover** — find a parallel ecosystem (IG, GitHub, arXiv, Twitter, Reddit)
