# Story 2.2: Per-Archiform Codegen Pass + Cypher DDL Byte-Equivalence

**User Story**: As a future runtime, I want the per-archiform codegen pass to consume `schemas/memory-palace-0.1.0.json` and emit Zig extensions, TS extensions, Valibot validators, and Cypher DDL, with the generated `schema.cypher` byte-matching (or with documented, justified semantically-equivalent diffs against) the pre-migration hand-maintained file, so that Memory Palace becomes generated end-to-end without behavioral regression.
**FRs**: FR4
**Decisions**: D-018 (per-archiform codegen), D-028 (Triple/HAS_KNOWLEDGE/CONTAINS schema citizens), D-029 (pin verify in build), D-030 (gen_cypher.zig), NFR1 (byte-equivalence inherited), NFR5 (kNN perf no regression)
**Complexity**: medium
**Test Tier**: thorough

## Acceptance Criteria
- **AC1** [happy — generation runs end-to-end]: Given Story 2.1's pinned schema + Story 1.5's cutover-complete generator, When `bun run codegen` runs, Then `gen_zig.zig` emits Memory Palace type extensions to `src/lib/generated/memory-palace.types.ts`, `gen_ts.zig` emits TS extensions, `gen_valibot.zig` emits Valibot validators, and `gen_cypher.zig` emits `src/memory-palace/schema.cypher`; all five outputs carry NFR9 provenance headers naming `schemas/.pins/memory-palace-0.1.0.fp` as source.
- **AC2** [happy — Cypher byte-equivalence per FR4 + NFR1]: Given the generated `src/memory-palace/schema.cypher`, When `diff src/memory-palace/schema.cypher tests/fixtures/pre-migration-schema.cypher` runs, Then the diff is empty OR every diff line is registered under `tests/codegen/normalizations/cypher-*.md` with a documented semantic-equivalence justification (no silent diffs per `feedback_dreamball_ac_scope_retreat`).
- **AC3** [happy — Triple + HAS_KNOWLEDGE per D-028]: Given the generated `schema.cypher`, When `grep -E 'CREATE NODE TABLE Triple|CREATE REL TABLE HAS_KNOWLEDGE|CREATE REL TABLE CONTAINS.*Palace.*Agent|Aqueduct.*last_traversal_ts' src/memory-palace/schema.cypher` runs, Then all four matches are present (Triple table; HAS_KNOWLEDGE rel; Palace→Agent CONTAINS edge; Aqueduct.last_traversal_ts column).
- **AC4** [happy — smoke gates green]: Given the regenerated types + Cypher DDL, When `zig build smoke`, `scripts/cli-smoke.sh`, `scripts/server-smoke.sh` run, Then all pass — no behavioral regression vs pre-migration `schema.cypher`.
- **AC5** [perf — NFR5 kNN no regression]: Given the regenerated Cypher DDL applied to a 500-corpus fixture, When the kNN recall benchmark runs, Then p50 and p95 are within 25% of sprint-001's measured baseline (p50 = 8.7 ms, p95 = 9.1 ms; sprint-001 R5 cleared 23×, so a 25% guard is generous); regression fails CI.
- **AC6** [error — drift detection]: Given the schema is mutated to remove a known-required field (e.g., `Aqueduct.last_traversal_ts`), When codegen runs, Then either the coverage test from Story 2.1 fails OR the byte-equivalence diff fails — drift cannot land silently.

## Technical Notes
- `gen_cypher.zig` is the new generator added under D-030. Its emission rules MUST replicate the existing hand-maintained `schema.cypher` formatting conventions (whitespace, comment ordering, statement order); document any unavoidable normalization under `tests/codegen/normalizations/cypher-*.md`.
- Capture `tests/fixtures/pre-migration-schema.cypher` once at story start by copying the live `src/memory-palace/schema.cypher` from the parent commit; this is the byte-equivalence reference.
- Per D-021: the generated DDL must remain compatible with replay-from-CAS — if a normalization changes column order, ladybugdb migration semantics must be considered (out-of-scope correction surface; flag as blocker if discovered).
- The Memory Palace–extending TS types from `gen_ts.zig` extend `src/lib/generated/types.ts` (which is root-only); name the extensions to avoid collision (e.g., `MemoryPalaceInscription` vs root `Inscription` if any conflict).

## Scope Boundaries
- This story DOES: ship per-archiform codegen for Memory Palace; verify Cypher byte-equivalence; verify kNN perf; pass smoke gates.
- This story does NOT: add `archiform_fp` to genesis envelope (Story 2.3); author action manifest entries (Story 3.1); change kNN algorithm (out of sprint-002 scope per Cluster K deferral).
