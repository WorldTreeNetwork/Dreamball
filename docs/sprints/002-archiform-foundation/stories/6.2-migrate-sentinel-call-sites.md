**User Story**: As a Dreamball maintainer, I want both derived-fp sentinel call sites in `oracle.ts oracleSignAction` and `store.recordTraversal` migrated to consume Story 6.1's `signActionEnvelope` export (producing real Ed25519 single signatures over the canonical action payload), with a negative test confirming forged signatures fail verification and `docs/known-gaps.md` updated to mark the "scope substitution" debt closed, so that the silent-substitution regression class from sprint-001 S4.4 / S5.5 is closed and no `_sentinelFp` / derived-fp / placeholder bytes remain in any signature-emitting path.

**Decisions**: D-022 (bridge boundary preserved), D-023 (signActionEnvelope consumed here), D-025, SEC3 (real Ed25519), SEC6 (Ed25519-only — no PQ), TC2 (full gate set)
**Complexity**: small
**Test Tier**: smoke (with mandatory full-gate verification per `feedback_full_gate_verification`)
