# Story 2.3: Genesis Envelope `archiform_fp` Field with Implicit-Binding Back-Compat

**User Story**: As a future runtime, I want the genesis envelope CBOR shape to carry an immutable `archiform_fp` field, with sprint-001 envelopes lacking the field decoding successfully via implicit binding to `dreamball/memory-palace@0.1.0`, so that every ball declares its archiform on the wire from sprint-002 forward without breaking pre-existing instances.
**FRs**: FR5
**Decisions**: D-017 (archiform_fp immutable per ball), IC1 (additive back-compat), IC4 (sprint-001 instance compat), TC8 (content-addressing)
**Complexity**: medium
**Test Tier**: thorough

## Acceptance Criteria
- **AC1** [happy — round-trip new envelope]: Given a new genesis envelope is emitted with `archiform_fp = blake3(<canonical-bytes-of-schemas/memory-palace-0.1.0.json>)`, When the envelope is encoded then decoded via the regenerated CBOR codec, Then the decoded `archiform_fp` byte-equals the input fp (32 bytes blake3).
- **AC2** [happy — implicit binding back-compat]: Given a sprint-001 genesis envelope (captured under `tests/fixtures/sprint-001-instances/genesis-no-archiform-fp.cbor`) lacking the `archiform_fp` field, When the new decoder runs, Then decoding succeeds and the resulting struct has `archiform_fp = blake3(<canonical-bytes-of-schemas/memory-palace-0.1.0.json>)` (the implicit Memory Palace fp); no error raised; per FR5 acceptance.
- **AC3** [edge — immutability]: Given a ball's genesis envelope with a recorded `archiform_fp`, When any subsequent envelope or mutation is emitted for that ball, Then the recorded fp MUST be preserved unchanged (per D-017: "immutable for the ball's lifetime"); a Vitest exercises a mutation cycle and asserts no fp drift.
- **AC4** [error — fp mismatch detection]: Given a ball whose genesis declares one `archiform_fp` and a subsequent envelope is emitted claiming a different fp, When `jelly verify` (or the decoder consistency check) runs, Then the verifier emits a structured error naming both fps; commits with this drift fail CI.
- **AC5** [happy — full-gate green]: Given the field added, When the full gate set runs (`zig build test`, `zig build smoke`, `bun run check`, `bun run test:unit -- --run`, `scripts/cli-smoke.sh`, `scripts/server-smoke.sh`, `tests/e2e-cryptography.sh`), Then all pass — additive back-compat means sprint-001 fixtures still decode.
- **AC6** [PROTOCOL.md immutability note]: Given the field, When `docs/PROTOCOL.md` is reviewed, Then the genesis envelope section documents `archiform_fp` as "immutable for the ball's lifetime" (the prose lands here; full doc refresh is Epic 7).

## Technical Notes
- Adding `archiform_fp` to the genesis envelope is a CBOR shape change — but per IC1 it's additive back-compat (an optional field; missing → implicit Memory Palace fp). This MUST land via the regenerated codec from Story 2.2, not via hand-edited TypeScript.
- The implicit-binding default is computed once at decoder init: `MEMORY_PALACE_IMPLICIT_FP = blake3(readFile('schemas/memory-palace-0.1.0.json'))` — cached, not recomputed per decode.
- The decoder MUST be updated on both sides: Zig (`src/protocol_v2.zig` extensions via codegen) AND the wasm-loaded TypeScript decoder (via the regenerated codec). Both are emitted from Story 1.3's generator pipeline; this story exercises that pipeline against a wire-shape change.
- Per IC4: sprint-001 instances are throwaway, BUT a sprint-001 `jelly` build must still decode a sprint-002-produced canonical envelope (forward-compat is one-directional). The implicit-binding fixture proves backward-compat (sprint-001 → sprint-002 read); a separate fixture under `tests/fixtures/sprint-002-emitted/` proves sprint-002 emit → sprint-001 read does NOT trip on the new field (extra field ignored per CBOR open-extension semantics).
- This is the sprint's first wire-format addition. Capture sprint-001 fixtures BEFORE landing the codec change so the back-compat assertion has a canonical comparison set.

## Scope Boundaries
- This story DOES: add `archiform_fp` to genesis envelope shape via codegen; ship implicit-binding decoder default; ship round-trip + back-compat tests; add PROTOCOL.md immutability prose line.
- This story does NOT: change any other wire-format field; build any per-archiform validation hooks (out of sprint-002 scope); ship full Epic 7 doc refresh.
