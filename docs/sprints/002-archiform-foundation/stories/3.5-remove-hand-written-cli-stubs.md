# Story 3.5: Remove Hand-Written `src/cli/palace_*.zig` Stubs + CLI Dispatch Cutover

**User Story**: As a release engineer, I want one atomic commit that removes the hand-written `src/cli/palace_{mint,inscribe,add_room,rename_mythos,move}.zig` stubs, updates `src/cli/palace.zig` to dispatch to `src/cli/generated/*` exclusively, and leaves only the generated dispatchers in place, so that the FR7 acceptance ("no hand-written verb dispatch in `src/cli/palace*.zig`") is closed atomically with all CI gates green.
**FRs**: FR7
**Decisions**: D-013 (flat-table dispatch — preserved), D-019, D-022, TC2 (full gate set required)
**Complexity**: small
**Test Tier**: smoke

## Acceptance Criteria
- **AC1** [happy — atomic stub removal]: Given Stories 3.2–3.4 have all projected verbs green, When the cutover commit lands, Then it deletes `src/cli/palace_mint.zig`, `src/cli/palace_inscribe.zig`, `src/cli/palace_add_room.zig`, `src/cli/palace_rename_mythos.zig`, `src/cli/palace_move.zig` (5 files); updates `src/cli/palace.zig` flat-table dispatch (per D-013) to point at `src/cli/generated/palace_*.zig`.
- **AC2** [happy — full smoke gate green]: Given the cutover, When `scripts/cli-smoke.sh` runs covering all 5 verbs, Then all pass with no behavioral regression.
- **AC3** [grep audit — no hand-written verb dispatch remains]: Given the cutover, When `find src/cli -name 'palace_*.zig' -not -path '*/generated/*'` runs, Then results are zero (the only `palace_*.zig` files are under `src/cli/generated/`); per FR7 acceptance.
- **AC4** [grep audit — palace.zig only references generated]: Given the cutover, When `grep -E '@import.*palace_(mint|inscribe|add_room|rename_mythos|move)' src/cli/palace.zig` runs, Then every match is to a `generated/` path; no legacy references.
- **AC5** [happy — full-gate verification]: Given the cutover, When the full gate set runs (`zig build test`, `zig build smoke`, `bun run check`, `bun run test:unit -- --run`, `scripts/cli-smoke.sh`, `scripts/server-smoke.sh`, `tests/e2e-cryptography.sh`), Then all 7 gates pass per TC2 + `feedback_full_gate_verification`.
- **AC6** [error — rollback path]: Given a regression discovered post-cutover, When `git revert <cutover-sha>` is invoked, Then the hand-written stubs are restored and the dispatch table reverts cleanly (single-commit cutover guarantees rollback safety).

## Technical Notes
- Per D-013: the flat-table dispatch architecture is preserved — only the targets change (from hand-written to generated). The dispatch shape is structurally identical.
- This is the sister story to 1.5 — same single-commit-cutover discipline, same revert-safety property.
- The `src/cli/show.zig` verb (read-only) is NOT in the manifest scope per Phase 1B Q7 (only the 5 mutating verbs); leave hand-written.
- Per `feedback_full_gate_verification`: AC5 requires ALL 7 gates locally, not just `cli-smoke.sh`. Narrow tests pass false-positive on this class of cutover.

## Scope Boundaries
- This story DOES: delete 5 hand-written verb stubs; update flat-table dispatch; verify full gate set.
- This story does NOT: change wire format; ship TS client / MCP (Epic 4); ship wasm action runtime (Epic 5); touch `src/cli/show.zig` or other read-only verbs.
